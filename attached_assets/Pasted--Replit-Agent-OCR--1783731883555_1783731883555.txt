# Final Requirement

The OCR module must work end-to-end:

1. User uploads passport image.
2. Image is automatically optimized.
3. OCR runs.
4. MRZ is detected and parsed.
5. Passport fields are extracted.
6. Validation is performed.
7. Confidence score is calculated.
8. Data is returned in structured JSON.
9. Passport image is stored.
10. The extracted data can be saved directly into the existing `visa_applications` table.

Do not generate partial implementations. Build the complete production-ready feature integrated with the current project architecture.
