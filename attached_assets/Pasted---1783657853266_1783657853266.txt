يمكنك اعتماد نفس فكرة **التحقق من الصورة الشخصية** ولكن مخصصة لمسح جواز السفر واستخراج البيانات تلقائياً (Passport OCR).

إليك وصف احترافي يمكنك إعطاؤه للمطور أو للـ AI:

---

# آلية مسح جواز السفر (Passport OCR)

بعد أن يختار المستخدم صورة الجواز من الكاميرا أو المعرض، يبدأ النظام تلقائياً بفحص الصورة واستخراج البيانات دون تدخل المستخدم.

## المرحلة الأولى: التحقق من جودة الصورة

يعرض النظام رسالة:

```
جاري التحقق من صورة جواز السفر...
```

مع مؤشر تحميل.

يقوم النظام بفحص:

* ✔ ظهور صفحة البيانات كاملة.
* ✔ عدم قص أي جزء من الجواز.
* ✔ وضوح النصوص.
* ✔ عدم وجود انعكاس ضوء.
* ✔ عدم وجود ضبابية.
* ✔ قراءة منطقة MRZ (السطرين أسفل الجواز).
* ✔ دقة الصورة كافية.

---

## إذا كانت الصورة غير مناسبة

يتوقف النظام قبل استخراج البيانات.

ويظهر:

```
❌ تعذر قراءة الجواز

السبب:

• يوجد انعكاس ضوء
• الصورة غير واضحة
• جزء من الجواز غير ظاهر
```

ثم يعرض زر

```
إعادة التقاط الصورة
```

---

## إذا كانت الصورة مناسبة

تظهر رسالة

```
✓ تم التحقق من صورة الجواز
```

ويتحول إطار الصورة إلى اللون الأخضر.

بعدها يبدأ مباشرة

```
استخراج بيانات الجواز...
```

مع دائرة تحميل.

---

# استخراج البيانات

يقوم النظام بقراءة:

* الاسم الكامل
* رقم الجواز
* الجنسية
* الجنس
* تاريخ الميلاد
* تاريخ الإصدار
* تاريخ الانتهاء
* دولة الإصدار
* مكان الميلاد
* MRZ
* صورة حامل الجواز

---

أثناء القراءة يظهر:

```
🔄 يتم استخراج البيانات...

██████████ 82%
```

---

# بعد نجاح القراءة

يتغير الزر إلى

```
✔ تم استخراج البيانات بنجاح
```

وتظهر بطاقة خضراء:

```
تم استخراج بيانات الجواز بنجاح

✓ الاسم
✓ رقم الجواز
✓ الجنسية
✓ تاريخ الميلاد
✓ تاريخ الانتهاء
✓ منطقة MRZ
```

ثم يتم تعبئة جميع الحقول تلقائياً.

---

# في حال عدم القدرة على قراءة بعض الحقول

إذا قرأ النظام معظم البيانات لكن فشل في حقل واحد:

```
تم استخراج معظم البيانات

⚠ لم نتمكن من قراءة:

• مكان الميلاد

يرجى إدخاله يدوياً.
```

ولا يعيد المستخدم تصوير الجواز بالكامل.

---

# إذا فشل OCR بالكامل

بدلاً من الرسالة الحالية:

```
حدث خطأ في خدمة القراءة
```

يفضل أن تكون الرسالة أكثر وضوحاً:

```
❌ تعذر استخراج بيانات الجواز

الأسباب المحتملة:

• الصورة غير واضحة.
• يوجد انعكاس ضوء.
• الجواز غير ظاهر بالكامل.
• جودة الصورة منخفضة.
• تعذر قراءة منطقة MRZ.

يرجى إعادة تصوير الجواز أو إدخال البيانات يدوياً.
```

مع زرين:

* 🔄 إعادة التصوير
* ✍️ إدخال البيانات يدوياً

---

## تحسين تجربة المستخدم

أضف شريط حالة يوضح تقدم العملية بالكامل:

```
✓ التحقق من الصورة
⏳ استخراج البيانات
○ مراجعة البيانات
✓ اكتمال العملية
```

ثم بعد الانتهاء:

```
✓ التحقق من الصورة
✓ استخراج البيانات
✓ مراجعة البيانات
✓ اكتملت العملية
```

بهذا يشعر المستخدم أن التطبيق يعمل باحترافية، ويعرف في أي مرحلة هو، بدلاً من ظهور رسالة خطأ عامة لا توضح سبب المشكلة أو ما الذي يحدث في الخلفية.
