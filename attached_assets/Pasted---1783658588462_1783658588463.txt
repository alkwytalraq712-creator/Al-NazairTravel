# تحسينات مطلوبة قبل الإطلاق (Medium Priority)

## 1. ربط بحث الرحلات بـ API حقيقي

**الوضع الحالي**

* نتائج البحث عبارة عن بيانات تجريبية (Mock Data) لأربع شركات طيران فقط.

**المطلوب**

* ربط شاشة البحث بمزود رحلات حقيقي مثل:

  * Amadeus
  * Sabre
  * Travelport

ويجب أن يدعم:

* البحث في الوقت الحقيقي.
* أسعار محدثة.
* المقاعد المتوفرة.
* مدة الرحلة.
* الرحلات المباشرة والتوقف.
* سياسة الأمتعة.
* أنواع الدرجات.

---

## 2. حفظ صور التأشيرة

**الوضع الحالي**

بعد رفع:

* الصورة الشخصية
* صورة الجواز

يقوم التطبيق بالتحقق فقط، لكنه لا يحفظ الصور.

---

**المطلوب**

رفع الصور إلى Object Storage مثل:

* AWS S3
* Cloudflare R2
* Supabase Storage
* Azure Blob Storage

ثم حفظ داخل قاعدة البيانات:

* رابط الصورة الشخصية
* رابط صورة الجواز
* وقت الرفع
* نوع الملف
* حجم الملف
* حالة التحقق

مثال:

```text
passport_image_url
personal_photo_url
uploaded_at
verification_status
storage_provider
```

كما يجب حذف الصور عند حذف الطلب أو بعد انتهاء صلاحية الطلب وفق سياسة الاحتفاظ بالبيانات.

---

## 3. إكمال صفحات الحساب

الروابط الحالية:

* تعديل الملف الشخصي
* الأمان والخصوصية
* المساعدة والدعم

تعيد null.

---

**المطلوب**

إنشاء الصفحات وربطها بالتنقل.

### تعديل الملف الشخصي

* الصورة الشخصية
* الاسم
* البريد الإلكتروني
* الهاتف
* الجنسية
* تاريخ الميلاد
* اللغة

---

### الأمان والخصوصية

* تغيير كلمة المرور
* تفعيل OTP
* إدارة الأجهزة
* سياسة الخصوصية
* حذف الحساب

---

### المساعدة والدعم

* الأسئلة الشائعة
* الدردشة المباشرة
* واتساب
* البريد الإلكتروني
* إنشاء تذكرة دعم
* معلومات التواصل

---
